## Что было сделано в этом раунде

### 1. Панель POSITIONS (позиции)

Добавлен новый клиент `SkyPilot.Core.Web.PositionsClient`:

- Запрашивает `GET /api/v1/positions?lat=…&lon=…&radius=…` раз в 60 секунд.
- Хранит `PositionEntry` (callsign, facility, frequency, state, name, onlineSince, nextBooking).
- Статический метод `Merge()` объединяет каталог с онлайн-диспетчерами из FSD-сессии: сеть побеждает по частоте и статусу, дополнительные онлайн-позиции добавляются в конец, порядок — онлайн → бронь → свободно, затем по позывному.

В `MainWindow.xaml.cs`:

- `DispatcherTimer` на 60 с запускает `RefreshPositionsAsync`.
- Список `_lastPositions` обновляется при каждом обновлении диспетчеров (`UpdateControllers`).
- Двойной клик по строке настраивает COM1.

Панель занимает пустую область в средней колонке между COM-панелями и полосой VOICE/PTT.

Тесты в `SkyPilot.Core.Tests.PositionsClientTests` — 8 случаев, включая проверку порядка сортировки и приоритета сети над каталогом.

### 2. Кнопка CHARTS (схемы)

Кнопка в верхней панели открывает контекстное меню:

- **Departure charts (ИКАО)** — аэродром вылета из плана полёта.
- **Arrival charts (ИКАО)** — аэродром назначения.
- **Nearest airport charts (ИКАО)** — ближайший известный аэродром (поле `_nearestAirport`, будет заполняться позже).
- **Charts for…** — диалог ввода произвольного ИКАО.

Каждый пункт открывает `https://chartfox.org/<ИКАО>` в браузере по умолчанию. Пункты недоступны, если ИКАО не известен.

### 3. Исправления дизайна

- Иконки PIN и настроек заменены с нечитаемых глифов на векторные `Path`-геометрии (Material Design, 24×24).
- Средняя колонка Row 2 теперь занята панелью POSITIONS вместо пустого пространства.
- Окно первого запуска (`FirstRunWindow`) расширено до 680 px — кнопка «Сохранить и продолжить» видна полностью.

### 4. Исправление ошибки сборки

`CS0649`: поле `_nearestAirport` никогда не присваивалось — переведено в авто-свойство (`{ get; set; }`).
